# 机械星球

一颗被轨道矿车环绕的金属星球，在浏览器里跑的 3D 小游戏。星球被能量河道分成面积相当的四个区域，你可以驾驶一台能在机器人和载具之间变形的机器，沿着环路穿行、接管区域里的其他机器、点亮四座信标、收集散落的能量晶块。

## 怎么玩

### 操作

- **方向键或 W A S D**：上下前进后退，左右转向。机器人原地转身，载具按车速转弯。
- **Shift**：机器人奔跑，载具加速。
- **空格**：跳跃，只有机器人形态能跳。
- **F**：在机器人形态和载具形态之间变形。
- **E**：和信标互动，或者摸摸路过的机械鹿。
- **鼠标点击另一台机器**：接管它。**Tab**：回到主角。
- **M**：拉远到星球视角，看整颗星球和天上的环轨。
- **J**：打开日志。
- **H**：打开操作指南。
- **P**：拍照模式，隐藏界面；再按一次或按 Esc 退出，也可以从角落保存图片。
- **鼠标拖动**旋转视角，**滚轮**缩放。

触屏设备会显示摇杆和按钮：摇杆移动转向，右下角按钮负责跳跃、变形、回到主角和奔跑/加速。

### 目标

1. 走到每个区域中心的信标旁，按 E 点亮它。四座都点亮后会放烟花。
2. 点击另外三个区域里的机器接管它们，把每种机器都开一遍，按 Tab 回到主角。
3. 捡起星球上散布的 12 块能量晶块。
4. 看看天上的矿石列车，摸摸机械鹿，翻开日志看看自己走过的区域和完成的事。

## 星球上有什么

### 四个区域

- **能量河流**：青绿色的低地，发光的主河道、支流和泉眼在峡谷里蜿蜒，环路有两座桥跨过河道。
- **铁堡**：银白色和金色的层层塔楼，台阶状的基座、天桥和回廊，中心是一片开阔的广场。
- **方舟号**：停在一大片倾斜甲板上的巨型方舟，船体半埋进地面，周围绕着管道和吊车。
- **暗影要塞**：紫黑色的高地，围墙、炮塔和激光栅栏围着一颗危险的核心。

四个区域面积大致相等，颜色和地形在边界处平滑过渡，机器人和载具都能自由走遍全星球。

### 环路和桥

一条闭合的金属环路把四个区域串起来，另有四条支路通进各区域。路面压实，两侧有发光边线；环路在能量河流区域有两座带栏杆的拱桥跨过水面。路面自带缓坡，机器人和载具都能开上去。

### 星球上的机器

- 每个区域有一台可以点击接管的机器，接管后可以驾驶、变形，按 Tab 回到主角。
- 每个区域还有巡逻的机器和面对面互射光炮的机器，它们会在机器人形态和载具形态之间来回变形，开一段路再站起来巡逻。
- 地上有机械鹿走来走去，摸两次就会跟着你走一段。

### 天上的列车

三圈永久的轨道环绕星球，各跑着一列运矿列车，车上装着琥珀色、青色和淡金色的矿石。轨道固定在星球外，不会和地面相交；更外圈还有几颗慢慢翻滚的废弃卫星。

### 信标和晶块

四个区域中心各有一座信标，走到旁边按 E 点亮。星球表面散着 12 块发光晶块，开过去就能捡起来，全部捡齐也会放烟花。

## 从源码运行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开终端里显示的地址（默认 http://localhost:5173 ）即可。

其他命令：

```bash
npm run build     # 构建静态站点到 build/
npm run preview   # 预览构建结果
npm run check     # 类型检查
```

## 离线包

`release/package.sh` 会构建游戏，并把它和启动脚本组装到项目旁边的 `机械星球-离线版` 文件夹：

```bash
bash release/package.sh
```

打开 `机械星球-离线版` 文件夹：

- **macOS**：双击「开始游戏.command」。它会在本机起一个临时网页服务并自动打开浏览器，不需要联网，也不用装东西。第一次打开时如果 macOS 提示「无法验证开发者」，在「开始游戏.command」上点右键选「打开」。玩的时候不要关掉弹出来的终端窗口，关掉它游戏就退出了。
- **Windows / Linux**：进入 `game` 文件夹，运行 `python3 -m http.server 8765`（Windows 上用 `python -m http.server 8765`），然后浏览器打开 http://localhost:8765 。需要先装 Python 3。直接双击 `game/index.html` 打不开，因为浏览器不允许这样加载角色模型。
