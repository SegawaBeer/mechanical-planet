# 机械星球

一颗可以开着机器人到处跑的金属小星球，在浏览器里玩的 3D 小游戏，黑客松一天内做完。

## 怎么玩

**直接玩（macOS）**：到 Releases 页面下载 `mechanical-planet-offline-macos.zip`，解压后双击「开始游戏.command」，浏览器会自动打开游戏。不需要联网，也不用装东西。玩的时候不要关掉弹出来的终端窗口，关掉它游戏就退出了。

第一次打开时，macOS 可能提示「无法验证开发者」。这时在「开始游戏.command」上点右键，选「打开」就行。

**Windows / Linux**：进入解压后的 `game` 文件夹，运行 `python -m http.server 8765`，然后用浏览器打开 http://localhost:8765 。需要先装 Python 3。直接双击 `index.html` 打不开，因为浏览器不允许这样加载角色模型。

**从源码运行**：

```bash
npm install
npm run dev
```

## 星球上有什么

- **四个区域**，相互连通，颜色自然过渡：
  - 能量河流：清亮的青色调，发光的河道和能量泉眼。
  - 铁堡：晴天，亮银白和金色的塔楼群，塔之间架着天桥。
  - 方舟号：糖果色，一艘半埋在地里的巨型战舰，周围有吊车和管道。
  - 暗影要塞：阴暗的紫黑色，城墙带品红色发光轮廓，有激光栏和飘落的火星。
- **天气和灯光随区域变化**，走进新区域时会平滑切换。
- **主角**是一台能在人形和载具之间变形的机器人。
- **接管其他角色**：每个区域有一台可以点击接管的机器人，接管后可以驾驶、变形，按 Tab 回到主角。
- **热闹的星球**：每个区域有巡逻的机器人，还有面对面互射光炮的机器人，地上有机械鹿走动。
- **天空**：金色运矿列车在空中跑，轨道在车头前铺出、车尾后消失。废弃卫星沿着各自的轨道慢慢翻滚。
- **收集**：12 块能量晶块，捡齐会放烟花。四个区域中心各有一个信标，可以点亮。

## 操作

- 方向键或 WASD：移动和转向
- Shift：加速
- 空格：跳
- F：变形（人形 / 载具）
- E：互动
- 鼠标点击机器人：接管它
- Tab：回到主角
- M：查看整颗星球
- J：日志
- H：帮助
